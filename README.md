 Java Practice Projects

A collection of Java exercises created to practise programming fundamentals, problem-solving, and clean code.

 Topics covered

- Arrays and lists
- Strings and text processing
- Loops and conditional statements
- Recursion
- Mathematical calculations
- Date and calendar logic
- Java streams
- Custom iterators

  Included exercises

Some examples in this repository include:

- Anagram Checker
- Area Calculator
- Array Adder, Filter, Modifier, and Sorter
- Calendar Builder
- Factorial and Fibonacci
- Palindrome Checker
- Prime Finder
- String Concatenator
- Weather Station
- Weekend Calculator
